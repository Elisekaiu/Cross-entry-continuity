# 验证范围、限制与不支持

| 情况 | 结论 | 怎么处理 |
| --- | --- | --- |
| iOS 原生 ChatGPT App + Shortcuts | **已在真实架构使用** App 开关信号 | 只上报状态，不上传正文 |
| MacBook + Chrome + ChatGPT 网页登录 | **已实际使用** | 保持正确 Chat 页面打开；不保证从 iOS 自动切窗 |
| Linux VPS + Node.js + 另一 Agent 的 Hook | **已实际使用** | 限制等待、按需拉取，成功 ACK、失败放弃 |
| 反向读取 Codex rollout JSONL | **已实际使用** | 非模型增量导出、游标、幂等；依赖日志格式 |
| Windows / Linux 桌面 Chrome | **理论可能，未实际验收** | 检查常驻浏览器、登录态、权限及后台脚本生命周期 |
| Edge / Brave / Arc（Chromium） | **理论可能，未实际验收** | 检查扩展/标签 API 与 DOM 适配 |
| iOS Safari / iOS Chrome 自身运行桌面扩展 | **不作为受支持路径** | 另备桌面 Chromium 设备 |
| iOS 自动识别刚刚切换到哪个 Chat 会话 | **未解决** | 不猜 conversation ID，无法确认就 fail closed |
| 手机关掉后电脑页面自动打开对应聊天 | **未解决** | 电脑需事先在目标聊天页面；手动选择更可靠 |
| Chat 自动每次执行 bootstrap / continuity_read | **不保证** | 优化工具描述与指令；必要时轻提醒；不要夸称 100% |
| Chat 每轮都知道真实时间差 | **不保证** | 宿主/Hook 注入可信时间戳比提示 LLM 猜时间更可靠 |
| 私有网页版 API / DOM 结构 | **随版本变化** | 失败则降级或停用；不能承诺维护兼容所有版本 |
| 生产代码直接拷贝到别人的服务器 | **不支持** | 生产私有记忆服务与内部路由并未公开；参考示例需自行适配 |

**其他现实限制：** 多设备并发打开多个 ChatGPT 标签时的选择歧义、回复仍在 streaming、重新生成分支、懒加载的长聊天、编辑后消息 ID 不变、浏览器扩展后台 MV3 休眠、Shortcuts 自动化权限提示、数据库失联/临时过期、工作区切换，均可能导致丢片段或不应同步。**以不错误注入为首要原则。**
