# FAQ

**Q：不用 MacBook 可以吗？**

可以替换成能长期开启 Chromium、支持扩展与真实 Chat 登录态的桌面环境，但我们只实测了 MacBook + Chrome。Windows、Linux 等应写作「预计可行，未验收」。

**Q：有 iPhone 不就能用 Shortcuts 直接传 conversation ID 吗？**

不能这样假设。Shortcut 的 App 开关自动化只传表面状态；ChatGPT 原生 App 没有向普通快捷指令开放完整聊天正文/当前会话 ID 的通用接口。

**Q：为什么不直接让 ChatGPT 每次给我一份总结？**

可以，但这是一个不同的取舍。我们尽量把导出、裁剪、去重和存储放在不需要模型参与的代码里，只在真正需要接续时注入很短的背景。

**Q：新聊天会自动读取 bootstrap 吗？**

可以在 instructions 和工具说明里约定「新会话、明确回来、离开很久后」读取一次。实际是否主动调用取决于模型和当轮上下文；需要时轻轻提醒它读取就好。

**Q：失败后不重试会漏消息吗？**

会。我们选择「可控丢失」而不是「错抓/无限等待/错乱上下文」。有需要时可由人手动查看诊断并重做一轮全新的转场，而不是自动无限重播旧任务。

**Q：开源项目里包含完整的长期记忆服务吗？**

仓库整理了分层接口和使用方式。你可以接入自己的记忆工具，每个人的原文、长期记忆和服务配置留在自己的环境里。


**Q：另一个 AI 平台也没有 webhook，可以照着做吗？**

可以借鉴架构，但**不能保证可以复用 ChatGPT 的 DOM 扩展**。先检查其条款、个人聊天导出/页面访问能力，以及另一边的 Hook、存储与认证方式。可只部署 checkpoint 和日志增量读取，不必复制整套系统。详见 [适配指南](ADAPTERS.md)。

**Q：只有陪伴型 AI 才会用到吗？**

当然不限于此。多个 Agent 协作、生活与工作助手并行、跨设备聊天都可以借鉴。长期陪伴只是我们最熟悉的出发点。
